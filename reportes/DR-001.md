| **Título** | Las imágenes de producto se muestran incorrectas/rotas para el usuario `problem_user` |

## Precondición

El usuario ha iniciado sesión con la cuenta `problem_user` / `secret_sauce` (una de las cuentas de prueba que Sauce Demo ofrece intencionalmente con comportamientos defectuosos, pensada para practicar reporte de bugs).

## Pasos para reproducir

1. Ir a la página principal de Sauce Demo.
2. Iniciar sesión con usuario `problem_user` y contraseña `secret_sauce`.
3. Observar las imágenes de los productos listados en la página de inventario.

## Resultado esperado

Cada producto debe mostrar su imagen correspondiente (por ejemplo, la mochila muestra una imagen de mochila, la camisa muestra una imagen de camisa, etc.), igual que con el usuario `standard_user`.

## Resultado actual

Todas las imágenes de producto se muestran iguales entre sí (la misma imagen repetida, por ejemplo la del perro), sin corresponder al producto real que describen.

## Evidencia

Ver `evidencias/clase07/` — captura de la página de inventario con `problem_user` mostrando las imágenes incorrectas, comparada contra la captura equivalente con `standard_user`.

## Análisis (cadena Error → Defecto → Fallo)

- **Error:** en el desarrollo de la cuenta de prueba `problem_user`, se asignó de forma incorrecta (intencional, para fines de práctica de QA) la misma referencia de imagen a todos los productos del catálogo, en vez de mapear cada producto a su imagen correspondiente.
- **Defecto:** el código que asocia productos con sus imágenes contiene una referencia fija/incorrecta para las cuentas de tipo `problem_user`, presente en el sistema aunque no se haya ejecutado todavía.
- **Fallo:** al iniciar sesión con `problem_user` y visualizar el inventario, el defecto se manifiesta: las imágenes mostradas no corresponden a los productos reales.

## Atributo de calidad afectado (ISO/IEC 25010)

**Adecuación funcional** — el sistema no muestra la información visual correcta que el usuario necesita para identificar el producto. También impacta ligeramente en **Usabilidad**, ya que dificulta que el usuario reconozca visualmente lo que está comprando.

## Estado

Abierto.
